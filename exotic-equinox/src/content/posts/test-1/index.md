> **ข้อมูลสมมุติสำหรับเลือกแบบบทความ** — โจทย์และ Flag ในหน้านี้สร้างขึ้นเพื่อสาธิต รูปปกใช้ไฟล์เดิมในโปรเจกต์

บทความแบบนี้เหมาะกับโจทย์ที่อยากอธิบายละเอียด อ่านจากบนลงล่างตามลำดับการแก้ มีรูปปกด้านบนและสารบัญสำหรับข้ามไปยังส่วนที่สนใจ

**ลองเทียบรูปแบบ:** [Test 2 — แบบบันทึกหลายโจทย์](/posts/test-2/) · [บทความ Cyber Hero](/posts/cyberheronakornchiangrai/cyber-hero-nakorn-chiangrai/)

## 01 — ข้อมูลโจทย์

| รายการ | รายละเอียดสมมุติ |
| --- | --- |
| ชื่อโจทย์ | A Hex Letter |
| หมวด | Cryptography |
| ระดับ | Beginner |
| คะแนน | 100 |
| เครื่องมือ | Python 3 และโมดูลมาตรฐาน |

โจทย์ให้ข้อความที่อ่านไม่ออกหนึ่งบรรทัด พร้อมคำใบ้ว่า “ลองอ่านทีละคู่”

```text title="message.txt"
4354467b6865785f69735f66756e7d
```

เป้าหมายคือหาว่าข้อความแทนข้อมูลด้วยวิธีใด และแปลงกลับมาเป็น Flag

## 02 — สังเกตและตั้งสมมุติฐาน

อักขระทั้งหมดอยู่ในช่วง `0–9` และ `a–f` และมีจำนวนเป็นเลขคู่ จึงตั้งสมมุติฐานว่าเป็นเลขฐานสิบหก (hexadecimal) ซึ่งใช้สองหลักแทนหนึ่งไบต์

ทดลองอ่านส่วนต้นก่อน:

| Hex | ตัวอักษร ASCII |
| --- | --- |
| `43` | `C` |
| `54` | `T` |
| `46` | `F` |
| `7b` | `{` |

ข้อความเริ่มต้นเป็น `CTF{` จึงมีหลักฐานสนับสนุนให้ลองถอดทั้งบรรทัด

## 03 — เขียนสคริปต์แก้โจทย์

ใช้ `bytes.fromhex()` แปลงเลขฐานสิบหกเป็นไบต์ จากนั้นถอดเป็นข้อความ UTF-8

```python title="solve.py"
encoded = "4354467b6865785f69735f66756e7d"
decoded = bytes.fromhex(encoded)
flag = decoded.decode("utf-8")

print(flag)
```

บันทึกโค้ดเป็น `solve.py` แล้วรันในโฟลเดอร์เดียวกัน:

```powershell
python solve.py
```

### ผลลัพธ์ที่คาดหวัง

```text
CTF{hex_is_fun}
```

**Flag สมมุติ:** `CTF{hex_is_fun}`

## 04 — ตรวจสอบคำตอบย้อนกลับ

การแปลงคำตอบกลับเป็น hex ควรได้ข้อความเดียวกับต้นฉบับ วิธีนี้ช่วยตรวจว่าเราไม่ได้พิมพ์ข้อมูลผิดระหว่างทดลอง

```python title="verify.py"
flag = "CTF{hex_is_fun}"
encoded = flag.encode("utf-8").hex()
assert encoded == "4354467b6865785f69735f66756e7d"
print("Verified:", encoded)
```

## 06 — สิ่งที่ได้เรียนรู้

- รูปแบบอักขระช่วยตั้งสมมุติฐาน แต่ต้องทดลองกับข้อมูลจริง
