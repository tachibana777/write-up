## Challenge 1 — A Small Message

### ข้อมูลจากโจทย์

**หมวด:** Cryptography · **คะแนนสมมุติ:** 100

โจทย์ให้ข้อความหนึ่งบรรทัด พร้อมคำใบ้ว่า “บางครั้งข้อความก็แค่เปลี่ยนรูปแบบ”

```text title="message.txt"
Q1RGe2Jhc2U2NF9pc19lbmNvZGluZ30=
```

เป้าหมายคือแปลงข้อความนี้กลับมาเป็น Flag โดยอธิบายได้ว่าเลือกใช้วิธีใดและเพราะอะไร

### การสังเกตและแนวคิด

ข้อความประกอบด้วยตัวอักษรภาษาอังกฤษ ตัวเลข และลงท้ายด้วย `=` จึงตั้งสมมุติฐานว่าอาจเป็น Base64 อย่างไรก็ตาม รูปแบบเพียงอย่างเดียวยังไม่ยืนยัน เราต้องลองถอดและตรวจสอบผลลัพธ์ด้วย

Base64 เป็นการเข้ารหัสรูปแบบข้อมูล (encoding) ที่ไม่ต้องใช้กุญแจลับในการแปลงกลับ จึงต่างจากการเข้ารหัสลับ (encryption)

### ขั้นตอนการแก้

1. คัดลอกข้อความให้ครบ รวมถึงเครื่องหมาย `=` ท้ายบรรทัด
2. ใช้โมดูล `base64` ที่มากับ Python ถอดข้อมูล
3. แปลงไบต์เป็นข้อความ UTF-8 แล้วตรวจรูปแบบคำตอบ

```python title="solve_base64.py"
import base64

encoded = "Q1RGe2Jhc2U2NF9pc19lbmNvZGluZ30="
decoded = base64.b64decode(encoded, validate=True)
print(decoded.decode("utf-8"))
```

หากติดตั้ง Python แล้ว สามารถบันทึกโค้ดเป็น `solve_base64.py` และรัน:

```powershell
python solve_base64.py
```

### ผลลัพธ์และ Flag

```text
CTF{base64_is_encoding}
```

**Flag สมมุติ:** `CTF{base64_is_encoding}`

สิ่งที่ได้เรียนรู้คือเริ่มจากวิธีที่ตรวจสอบได้ง่ายก่อน และเก็บทั้งข้อมูลต้นทางกับคำสั่งที่ใช้เพื่อให้ผู้อ่านทำซ้ำได้

## Challenge 2 — Hidden in Plain Text

### ข้อมูลจากโจทย์

**หมวด:** Forensics · **คะแนนสมมุติ:** 150

สมมุติว่าโจทย์ให้ไฟล์ `evidence.bin` และบอกว่ามีข้อความสำคัญซ่อนอยู่ภายใน สำหรับบทความสาธิตนี้ เราจะสร้างข้อมูลจำลองขึ้นเองเพื่อให้ผู้อ่านทดลองได้โดยไม่ต้องดาวน์โหลดไฟล์

### การสังเกตและแนวคิด

ไฟล์ไบนารีอาจมีข้อความที่อ่านได้ปะปนอยู่ จึงลองค้นหารูปแบบ `CTF{...}` ในข้อมูลก่อน วิธีนี้เหมาะกับตัวอย่างที่ Flag อยู่ในรูปข้อความธรรมดา แต่ไม่ได้แปลว่าจะใช้ได้กับทุกโจทย์

### ขั้นตอนการแก้

โค้ดด้านล่างสร้างชุดไบต์จำลองในหน่วยความจำ แล้วใช้ regular expression ค้นหา Flag โดยไม่ต้องเขียนไฟล์ลงดิสก์

```python title="solve_forensics.py"
import re

# ข้อมูลนี้สร้างขึ้นเพื่อสาธิต ไม่ใช่ไฟล์จากการแข่งขันจริง
data = (
    b"\x00\x01DEMO_HEADER\x00"
    b"ordinary notes\x00"
    b"CTF{look_for_readable_strings}"
    b"\x00\xffDEMO_END"
)

matches = re.findall(rb"CTF\{[^}\r\n]+\}", data)

if not matches:
    print("No flag found")
else:
    for match in matches:
        print(match.decode("ascii"))
```

หากต้องการเปลี่ยนไปอ่านไฟล์โจทย์ของตนเอง ให้แทนส่วนสร้าง `data` ด้วย:

```python
from pathlib import Path

data = Path("evidence.bin").read_bytes()
```

วาง `evidence.bin` ในโฟลเดอร์ที่รันคำสั่ง แล้วรันสคริปต์:

```powershell
python solve_forensics.py
```

### ผลลัพธ์และ Flag

```text
CTF{look_for_readable_strings}
```

**Flag สมมุติ:** `CTF{look_for_readable_strings}`

ในโจทย์จริง หากพบข้อความคล้าย Flag หลายจุด ควรตรวจบริบทและผลการส่งคำตอบด้วย สำหรับตัวอย่างนี้ผลลัพธ์ตรงกับข้อมูลที่เราสร้างไว้

## ปัญหาที่พบระหว่างทดลอง

| อาการ | สิ่งที่ควรตรวจสอบ |
| --- | --- |
| ถอด Base64 ไม่สำเร็จ | คัดลอกข้อความครบหรือไม่ มีช่องว่างหรืออักขระเกินมาหรือไม่ |
| เปิดไฟล์ไม่พบ | ชื่อไฟล์และโฟลเดอร์ที่รันคำสั่งตรงกับตำแหน่งไฟล์หรือไม่ |
| รูปในบทความไม่แสดง | ชื่อรูป นามสกุล และพาธสัมพันธ์กับไฟล์ Markdown ถูกต้องหรือไม่ |
| โค้ดในบทความไม่เป็นบล็อก | เปิดและปิดกรอบโค้ดด้วย backtick สามตัวครบหรือไม่ |

## วิธีเพิ่มภาพหน้าจอของตัวเอง

สร้างโฟลเดอร์ `images` ข้างไฟล์บทความนี้ แล้วบันทึกภาพหน้าจอ เช่น `challenge-01.png` และ `result-01.png`

```text
cyberheronakornchiangrai/
├── cyber-hero-nakorn-chiangrai.md
├── banner.webp
└── images/
    ├── challenge-01.png
    └── result-01.png
```

เมื่อมีไฟล์รูปแล้ว ให้เพิ่มบรรทัดต่อไปนี้ในตำแหน่งที่ต้องการแสดงรูป โดยนำออกจากกรอบโค้ด:

```markdown
![ภาพโจทย์ข้อแรก](./images/challenge-01.png)

![ผลลัพธ์หลังรันสคริปต์](./images/result-01.png)
```

ข้อความในวงเล็บเหลี่ยมใช้อธิบายภาพ ส่วนพาธในวงเล็บกลมต้องตรงกับไฟล์จริง ตัวอย่างชื่อรูปสองไฟล์นี้เป็นแนวทางให้เพิ่มภายหลัง จึงยังไม่แทรกเป็นรูปจริงในหน้าเว็บ

## สิ่งที่ได้เรียนรู้

- เริ่มจากการอ่านโจทย์และตรวจรูปแบบข้อมูลก่อนเลือกเครื่องมือ
- เขียนเหตุผลที่เลือกแต่ละวิธีควบคู่กับคำสั่ง ไม่บันทึกเฉพาะ Flag
- ใช้โค้ดสั้นที่ผู้อ่านทดลองซ้ำได้ และแสดงผลลัพธ์ที่คาดหวัง
- แยกข้อมูลที่สังเกตได้ออกจากสมมุติฐาน และบันทึกข้อจำกัดของวิธีที่ใช้
